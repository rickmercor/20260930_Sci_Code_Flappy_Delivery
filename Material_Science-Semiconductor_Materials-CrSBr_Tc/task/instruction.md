# Material_Science-Semiconductor_Materials-CrSBr_Tc

## Problem

Monolayer chromium sulfide bromide (CrSBr) is a two-dimensional ferromagnet in which the Cr³⁺
ions carry spin S = 3/2 on a rectangular lattice with two magnetic sites per unit cell. Its
magnetic order is described by the Heisenberg model

    H = -(1/2) Σ_{abij} S^T_{ai} J_{abij} S_{bj}

where a, b label sites within a unit cell, i, j label unit cells, and J is the exchange
tensor. Terms with a = b and i = j represent single-ion anisotropy and are treated separately
as K_{ai} = J_{aaii}/2. With this sign convention a positive isotropic J is ferromagnetic.

**Structure.** Use the bulk lattice constants a = 3.50 Å, b = 4.76 Å and c = 7.96 Å. The
in-plane primitive vectors are (a, 0, 0) and (0, b, 0), the layers stack along (0, 0, c), and
the two Cr sites sit at (0, 0, +d/2) and (a/2, b/2, −d/2) with a buckling d = 1.96 Å.
Neighbour shells are indexed by increasing Cr–Cr bond length over the **bulk** crystal, so the
ranking includes bonds to Cr atoms in the layers above and below.

**Exchange.** Inelastic neutron scattering on bulk CrSBr resolves isotropic exchange out to
the eighth neighbour. In the convention above,

  J₁ = 1.90, J₂ = 3.38, J₃ = 1.67, J₄ = 0.09, J₅ = 0.09, J₇ = −0.37, J₈ = 0.29 meV,

indexed by bulk shell. All further shells vanish. Anisotropic and antisymmetric exchange are
below the resolution of that measurement and are neglected.

**Anisotropy.** CrSBr is triaxial. Its point group is mmm, so every off-diagonal element of
K vanishes. The hard axis is c, the intermediate axis is a and the easy axis is b, so the
ordered moment lies along the crystal y direction. Using the isotropic invariance of the model
to set the hard-axis component to zero,

  K^xx = 0.066, K^yy = 0.087, K^zz = 0.0 meV.

These values have been fitted to the observed spin-wave dispersion using the same decoupling
scheme you are asked to apply below; a different treatment of the anisotropy requires a
different fitted triple.

Magnon energies are to be obtained from the poles of the transverse retarded Green's
functions. Decouple the higher-order Green's functions generated by the exchange part of the
Hamiltonian in the random phase approximation, replacing the local longitudinal spin operator
by its thermal average ⟨S^z_a⟩. For the single-ion anisotropy, do **not** use the random phase
approximation: apply Callen's decoupling instead, using Callen's parameter α = ⟨S^z_a⟩/(2S_a²).
The two treatments are combined into a single Hamiltonian whose eigenvalues are the magnon
energies.

At finite temperature the magnon energies are renormalised, because the Hamiltonian depends on
the sublattice magnetisation and on the magnon occupation, while both in turn depend on the
magnon energies. The sublattice magnetisation is to be obtained from Callen's expression

    ⟨S^z_a⟩ = [ (S_a − Φ_a)(1 + Φ_a)^(2S_a+1) + (S_a + 1 + Φ_a) Φ_a^(2S_a+1) ]
              / [ (1 + Φ_a)^(2S_a+1) − Φ_a^(2S_a+1) ]

where Φ_a is the site-resolved magnon occupation obtained from the fluctuation–dissipation
theorem,

    Φ_a = (1/N) Σ_{η,q} U_{aηq} n_B(ω_{ηq}) U^{-1}_{ηaq},

U is the matrix that diagonalises the Hamiltonian, ω_{ηq} are its eigenvalues, and n_B is the
Bose factor. The sum runs over the full set of eigenvalues at each q, and over a
Brillouin-zone mesh dense enough that the result has converged.

The Curie temperature is the temperature at which the sublattice magnetisation vanishes.

**Compute the Curie temperature of monolayer CrSBr, in K.**
