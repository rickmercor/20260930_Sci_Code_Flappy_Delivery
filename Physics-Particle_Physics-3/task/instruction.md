## Background

Shadow Hamiltonian simulation encodes a quantum state as the vector of expectation values of a set of operators closed under commutation with the Hamiltonian, so that Heisenberg-picture dynamics becomes a linear evolution of that vector generated by a shadow Hamiltonian whose size is the number of operators rather than the Hilbert-space dimension. For interacting spin systems the closed set grows exponentially, which removes the advantage. The source paper introduces classical pruning schemes that keep only the operators relevant to a chosen root observable: a graph-based selection in a predefined Pauli basis with a threshold on accumulated path weights, a Krylov construction with a multiplicative truncation criterion, and a hybrid of the two, and validates them on spin chains against exact diagonalisation, including a finite-temperature out-of-time-order correlator computed through a doubled-system protocol on a thermofield double state. This task applies the hybrid scheme, exactly as specified, to that thermal OTOC of a four-site longitudinal-field XXZ chain and reports the pruned value at a fixed time.
