## Background

A diffusion correction accelerates source iteration only if it approximates the scalar error operator generated by the transport discretisation. Here homogeneous vacuum inflow uses zero exterior traces, so leakage and boundary consistency enter both the transport and correction forms. The source paper treats constant-coefficient, isotropically scattering transport on a connected polytopal domain in d=2 or d=3. This task uses d=3 and implements its polynomial DG forms, angular jump lifting and exact macro-micro factorisation.

The mesh supplied to the geometry functions is guaranteed to be a valid conforming partition into convex three-dimensional polyhedra with convex planar polygonal faces. The vertices array contains (x,y,z) coordinates. Each cell is a list of its faces, and each face is a vertex-index cycle oriented counterclockwise as viewed from outside that cell; its right-hand normal points outward. Shared faces have identical vertex indices with reverse cyclic ordering in their two cells. No cycle repeats its first index at the end. The discrete space is broken total-degree P_p(K), not the tensor-product space: each polyhedron carries `(p+1)*(p+2)*(p+3)/6` independent coefficients. For each cell use the centre of its axis-aligned bounding box and its positive half-widths to set `xi=(x-centre_x)/halfwidth_x`, `eta=(y-centre_y)/halfwidth_y` and `zeta=(z-centre_z)/halfwidth_z`. The basis is `xi**a*eta**b*zeta**c`: increase t=a+b+c from 0 through p, then increase c from 0 through t, then increase b from 0 through t-c; a=t-b-c. Thus P2 has order `1,xi,eta,zeta,xi**2,xi*eta,eta**2,xi*zeta,eta*zeta,zeta**2`. Global ordering is cell-major followed by this basis order. Subdivisions used for integration add no DOFs or flux faces. All integrals refer to the exact polynomial integrals, evaluated to floating-point precision; mass and face products have degree at most 2p. Any mathematically equivalent integration method is permitted.

All form matrices have test rows and trial columns. Products of matrices denote matrix multiplication. A derivative or response matrix is a coefficient map in the same basis. Write M for the scalar L2 mass matrix and `T=sigma_t*M` for the unscaled collision mass. Here `B_m` is the full directional form in Eq. (17), including `(sigma_t/epsilon)*M`. The coefficient map `C_m` represents `(omega_m dot grad u)/sigma_t`, and `L_m` is the componentwise Riesz lifting of Eq. (78) with mass T. Stack these blocks over ordinates to form C and L; `K=C-L`, and Y has the same block layout. The element diameter h_K is the maximum distance between its vertices. With unit normal n pointing out of K-plus, `[v]=v_plus-v_minus` and `{v}=(v_plus+v_minus)/2` on an interior face. The boundary exterior value and exterior gradient are zero: `[v]=v_plus` and `{v}=v_plus/2`. These conventions also apply to vector-valued traces.

Section 2.1 uses `sigma_t_eps=sigma_t/epsilon`, `sigma_a_eps=epsilon*sigma_a`, `sigma_s_eps=sigma_t/epsilon-epsilon*sigma_a` and `c=1-epsilon**2*sigma_a/sigma_t`. Numeric inputs are finite real-valued scalars or arrays of the stated shapes. Quadratures have positive weights summing to one, unit directions, zero weighted first moment and second moment I/3. They admit one-to-one opposite-direction pairs with equal weights, including repeated directions. Check angular identities with atol=1e-12 and rtol=0. Array and scalar contract violations raise ValueError. Geometric validity, including closedness, planarity, convexity, outward orientation and conformity, is guaranteed; no general-purpose geometry validator is required. Check array shapes and vertex-index ranges. Vertex indices are integers.

For the requested verification note, define `chi=max_e(epsilon*tau_SIP_e/beta_e)`, including physical-boundary faces; chi<=1 means that every penalty uses its transport floor. Write `J=sum_m w_m*(B_m-T/epsilon)`. For stacked micro blocks Y and coupling K, define the relative micro-equation residual as `||(I+epsilon*Q*S*Q)*Y-K||_F/||K||_F`, where `S=block_diag(S_m)`, `S_m=solve(T,B_m-T/epsilon)`, and `Q=(I_omega-ones(N_omega,1)*w.T) kron I_N`.
