## Background

Block Krylov methods are projection-based techniques for approximating matrix functions without directly applying the function to the full matrix. They build a lower-dimensional subspace from repeated matrix-vector or matrix-block operations, then perform the expensive matrix-function computation on a reduced representation.

Using a block rather than a single starting vector can capture several directions of the underlying operator at once. Different choices of block inner product and normalization lead to distinct Krylov constructions, such as classical and global variants, which can produce different reduced models and therefore different approximations.

For matrix functions such as the exponential, the reduced problem provides a compact representation from which an approximation in the original space can be reconstructed. Comparing approximations generated by different Krylov formulations provides a numerical way to study how their projection and normalization choices affect the result.
